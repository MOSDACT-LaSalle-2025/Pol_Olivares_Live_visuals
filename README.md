# Pol_Olivares_Live_visuals


I created this generative art piece inspirated on JOHN WHITEY'S 60'S VISUALS  (https://archive.org/details/experimentsinmotiongraphics)
I used this tutorial mainly to understand how to create and control the moving lines https://www.youtube.com/watch?v=LaarVR1AOvs&t=6s
The instructions for the piece are: Press 1 for FIGURE 01 / Press 2 for FIGURE 02 / Press 0 to return here / Press P to save frame / w,a,s,d, to control the values of FIGURE 01 / y and t keys for color red and white
